# ModScan Pro Editions

ModScan Pro is available in two editions: Community and Business (Pro).

## Community Edition (Free & Open Source)
The Community Edition is designed for frictionless adoption. It does not require a license key or machine activation. 

**Features Included:**
- RTU/TCP connection
- Address scan
- Scan progress / cancel
- Read FC01–FC04
- Write FC05/06/15/16
- Batch read
- Sequential polling
- Topology / Logical Device Map
- Project save/load
- CSV export
- Remote tunnel

**How to build:**
Set the environment variable `NEXT_PUBLIC_EDITION=community` before building.

## Business Edition (Pro)
The Business Edition includes advanced professional workflows and requires a valid license key for activation.

**Features Included:**
- Everything in Community Edition
- Auto Report Generator
- AI Diagnostic Assistant
- Device Profile / Register Map Library
- Safe Write Audit Log
- Client-ready branded report
- SI Team license
- Priority support
- Offline enterprise deployment
